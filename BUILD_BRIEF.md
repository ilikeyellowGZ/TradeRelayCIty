# TradeRelayCity implementation brief

Source: `TradeRelayCity_Codex_Build_Prompt.md` supplied by the project owner on 7 November 2026. This repository tracks implementation progress in `docs/progress.md`; the original user brief is preserved unmodified.

The requested system is a private, invite-only AI-assisted MT5 application using a Cloudflare Worker, D1, Better Auth/passkeys, and per-user Windows connector installations. Local simulation is the first runnable mode. Live execution stays disabled until explicit owner action and successful broker-demo validation.

Owner clarification (8 November 2026): TradeRelayCity covers forex currency pairs and cryptocurrencies. EURUSD is the initial strategy example; other pairs require exact broker symbol mapping and contract checks. Metals and indices are outside the current scope. This clarification governs implementation of the preserved original brief.
